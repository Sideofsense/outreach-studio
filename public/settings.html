Tips for the summary

  • Concrete beats abstract. "Built RAGAS eval gates" beats "Passionate about AI products".
  • Numbers and scale signals stick. Vague outcomes don't.
  • Under 80 words. This is positioning, not your CV.
  • 5-7 achievements. Lead with the action, not the context.

Option A: Ollama (free, runs on your laptop)
  1. Install from ollama.com/download
  2. Pull a model: ollama pull llama3.1:8b
  3. Set in .env: 
    LLM_PROVIDER=ollama
OLLAMA_HOST=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b
  4. Restart server, then test:

Quality note: 8B local models follow "no banned words" rules less reliably than Sonnet. Larger models (70B, 32B) close the gap significantly.

Option B: Anthropic Claude Sonnet (paid, best quality, ~$1-$2 per 500 emails)
  1. Open console.anthropic.com, add billing ($5 covers ~2500 emails)
  2. API Keys tab, create key named "Outreach Studio"
  3. Set in .env: 
    LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-api03-your-key
ANTHROPIC_MODEL=claude-sonnet-4-5
  4. Restart server, then test:

Claude Pro/Max chat subscriptions do NOT include API access. Separate billing required.

Gmail App Password

One 16-character password for both sending (SMTP) and reading replies (IMAP).

First: enable 2-Step Verification if you haven't yet
  1. Go to myaccount.google.com/security
  2. "How you sign in to Google" - click 2-Step Verification - follow prompts
  1. Go to myaccount.google.com/apppasswords
  2. Select app: "Other (custom name)" - type "Outreach Studio" - Generate
  3. Copy the 16-char password, remove spaces: abcdefghijklmnop
  4. Set in .env: 
    SMTP_USER=you@gmail.com
SMTP_PASSWORD=abcdefghijklmnop
SMTP_FROM_NAME=Your Name

IMAP_USER=you@gmail.com
IMAP_PASSWORD=abcdefghijklmnop
  5. Restart server, then test both:
